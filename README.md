# Denteste - Base Frontend

Base estrutural para site de consultório odontológico, com layout moderno, mobile first e componentes reutilizáveis.

## Estrutura de pastas sugerida

```
src/
  assets/
  components/
    header.html
    hero.html
    section-services.html
    section-differentials.html
    section-about.html
    card.html
    footer.html
  index.html
  styles.css
```

## Componentes

- **Header** (`src/components/header.html`)
- **Hero** (`src/components/hero.html`)
- **Seções modulares** (`src/components/section-*.html`)
- **Card reutilizável** (`src/components/card.html`)
- **Footer** (`src/components/footer.html`)

## Estilos

`src/styles.css` organiza tokens de design, tipografia, layout e estilos de componentes seguindo mobile first.
